# 📑 Стек вызовов
- Во внутренней части компьютера используется стек вызова.
- Также есть так называемый стек вызова функций

```js
function greet2(name) {
  console.log("how are you, " + name + "?");
}

function bye() {
  console.log("ok bye!");
}

function greet(name) {
  console.log("hello, " + name + "!");
  greet2(name);
  console.log("getting ready to say bye...");
  bye();
}

greet("adit");
```
---
1) Вызывается функция greet **(1 элемент стека)**
	1) Она выводит в консоль *"hello, adit!"*
2) Вызывается функция greet2 внутри функции greet **(2 элемент стека)**
	1) Выводится в консоль *"how are you adit?"*
	2) Функция заканчивает работу и возвращает управление внешней функции greet **(2 элемент убирается из стека)**
3) В консоль выводится *"getting ready to say bye..."*
4) Вызывается функция bye() внутри функции greet **(теперь bye 2 элемент стека)**
	1) Выводится в консоль *"ok bye!"*
	2) Функция заканчивает работу, передает управление внешней функции где была вызвана
	3) Убирается из стека
5) В стеке снова только 1 элемент greet
