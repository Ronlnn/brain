# 📑 Сортировка выбором 
- Базовая сортировка когда мы проходимся по массиву например и просто выборочно проверяем условие.
- По сути самый дефолт
- Например надо отсортировать массив от меньшего к большему числу
	- Проходим по массиву, и каждый элемент сравниваем и меняем местами наименьшие по порядку.
	- Все

Пример 
```js
function selectionSort(arr) {
  for (let i = 0; i < arr.length - 1; i++) {
    // i — граница между отсортированной и неотсортированной частью
    
    let minIndex = i; // предполагаем, что минимум — первый элемент
    
    // Ищем реальный минимум в неотсортированной части
    for (let j = i + 1; j < arr.length; j++) {
      if (arr[j] < arr[minIndex]) {
        minIndex = j; // нашли элемент меньше
      }
    }
    
    // Меняем местами найденный минимум с первым неотсортированным
    [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
  }
  
  return arr;
}

console.log(selectionSort([64, 25, 12, 22, 11]));
// Результат: [11, 12, 22, 25, 64]

```
