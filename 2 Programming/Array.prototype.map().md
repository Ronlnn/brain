# 📑 Array.prototype.map()
- Создает новый массив с результатами вызова функции для каждого элемента 
```js
array.map((element, index, array) => {
  return новоеЗначение;
});
```
- Возвращает новый массив той же длинны с преобразованными элементами
- Не изменяет исходный массив

Пример 
```js
// Удвоить все числа
[1, 2, 3].map(num => num * 2);
// [2, 4, 6]

// Преобразовать числа в hex
[0, 255].map(num => `#${num.toString(16).padStart(6, '0')}`);
// ['#000000', '#0000ff']

// Создать массив объектов
['a', 'b', 'c'].map((letter, i) => ({ id: i, value: letter }));
// [{ id: 0, value: 'a' }, ...]\
```
