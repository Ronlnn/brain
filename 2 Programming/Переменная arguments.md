# 📑 Переменная arguments
- Все аргументы функции находятся в псевдомассиве **arguments**
- Раньше в Js не было [[Rest (...) parameters]] и получить все аргументы функции можно было только через arguments
- Но у этого есть минусы 
	- Хотя arguments похож на массив, и его можно перебирать, он все же не массив.
	- У него нет методов массива. На подобии map 
	- И arguments содержит сразу все аргументы функции, мы не можем получить только часть

[[Стрелочные функции]] не имеют arguments. А если и попробуем обратиться к arguments то получим аргументы внешней "нормальной" функции
