# 📑 Карирование в JS
- Это техника в функциональном программировании, которая позволяет
	- Превратить функцию с несолькими аргументами в последовательность функций
		- Каждая из которых принимает толоко 1 значение

Пример 
```js
// Каррированная функция, складывающая два числа
function сложить(a) {
  return function (b) {
    return a + b;
  };
}

// Вызов каррированной функции
let результат = сложить(2)(3);
console.log(результат); // Выведет 5
```
