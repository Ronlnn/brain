# 📑 Разница между let и const
- Область видимости
	- var - функциональная обалсть видимость
	- Т.е доступна внутри функции, где была объявлена
	- let - блочная
	- Т.е внутри блока кода, где была объявлена
- Поднятие (Всплытие)
	- var - поднимаются вверх в области видимости
	- Их можно использовать еще до их объвления
	- let - не поднимаются
