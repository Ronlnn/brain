# 📑 Rest (...) parameters
- Остаточные параметры
- Нововведение в [[01 ES6]]
- Обозначаются через ... 
- Остаточные параметры именно функции
- Буквально означают "собери оставшиеся параметры и положи их в массив"
- Можем остаточные параметры использоваться и с остальными дефолтными параметрами
	- Но остаточными параметры всегда идут самыми последними
		- То есть ... в конце списка аргументов/параметров функции

Пример 
```javascript
function showName(firstName, lastName, ...titles) {
  alert( firstName + ' ' + lastName ); // Юлий Цезарь

  // Оставшиеся параметры пойдут в массив
  // titles = ["Консул", "Император"]
  alert( titles[0] ); // Консул
  alert( titles[1] ); // Император
  alert( titles.length ); // 2
}

showName("Юлий", "Цезарь", "Консул", "Император");
```
