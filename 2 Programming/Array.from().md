# 📑 Array.from()
- Array.from() - Создает новый экземпляр <mark style="background: #ABF7F7A6;">Array</mark> из массивоподобного или итерируемого объекта\
	- То есть можно взять строку например и сделать из нее массив. Или даже самому задать длинну и итд

### Синтаксис
```js
Array.from(arrayLike[, mapFn[, thisArg]])
```
- Параметры
	- arrayLike
		- Объект, который мы преобразуем в массив
	- mapFN
		- Функция вызываемая для каждого элемента массива
	- thisArg
		- Значение в качестве this при выполнении функции mapFn
### Возвращаемое значение
- Новый экземпляр Array
