# 📑 Spread (...) оператор расширения
- Мы знаем как получить массив из списка параметров [[Rest (...) parameters]]
- А оператор расширения делает ровно противоположное.
	- Получается список из массива
---
Примеры:
```javascript
let arr1 = [1, -2, 3, 4];
let arr2 = [8, 3, -8, 1];

alert( Math.max(...arr1, ...arr2) ); // 8
```
```javascript
let arr1 = [1, -2, 3, 4];
let arr2 = [8, 3, -8, 1];

alert( Math.max(1, ...arr1, 2, ...arr2, 25) ); // 25
```
```javascript
let arr = [3, 5, 1];
let arr2 = [8, 9, 15];

let merged = [0, ...arr, 2, ...arr2];

alert(merged); // 0,3,5,1,2,8,9,15 (0, затем arr, затем 2, в конце arr
```
# Что под капотом?
Оператор расширения использует итераторы как это делает цикл [[for...of]]
Также очень похоже с [[Array.from()]]
Но между `Array.from()`  и `[..obj]` есть разница
- Array.from() работает как с псевдомассивами так и с итерируемыми объектами
- а [...obj] только с итерируемыми объектами

Выходит, что если нужно сделать из чего угодно массив - то Array.from
