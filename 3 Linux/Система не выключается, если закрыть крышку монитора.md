# 📑 Система не выключается, если закрыть крышку монитора
---
- Чтобы ноутбук не засыпал при закрытии крышки, нужно отредактировать конфигурацию systemd

```bash
sudo nano /etc/systemd/logind.conf
```
---
- Найти и раскоментировать строку HandleLidSwitch и установить значени : ignore 

```bash
HandleLidSwitch=ignore
```
---
- Перезапустить сервис

```bash
sudo systemctl restart systemd-logind.service
```
