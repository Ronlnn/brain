# 📑 Стек
- Простая структура данных
- Работает по принципу *LIFO*
	- Last In Last Out
	- То есть элемент, который был последним добавлен в список, будет удален первым
- Это абстрактная структура данных, которая может быть реализована на базе различных конкретных структур
	- [[Односвязный список]]
	- [[Двусвязный список]]
	- [[Динамический массив]]
- В стеке хранится указатель на **вершину** (top), который указывает на последний добавленный элемент.
	- При добавлении нового -> указать смещается на него
	- При удалении -> возвращается к предыдущему элементу

### Основные операции
- **push(x)** - добавление элемента x на вершину стека
- **pop()** - удаление верхнего элемента из стека
- **peek()** / **top()** - возврат верхнего элемента без его удаления
- **isEpmty()** - проверка стека на пустоту
Все операции выполняются только с верхним элементом стека. Это ключевая особенность структуры
