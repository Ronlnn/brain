# 📑 О-большое

- Описывает скорость работы [[Алгоритм]]

- Время выполнения О-большое имеет вид O(n)
	- О-большое не сообщает скорость в секундах, а позволяет сравнить **количество операций**
	- Оно указывает насколько быстро возрастет время выполнения алгоритма
И например для проверки списка размером n бинарному поиску потребуется logn операций.
Тогда О-большое будет выглядеть O(logn)
